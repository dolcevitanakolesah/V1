# Italian Finds — simplified website

## What's changed
- Removed the top middle navigation menu.
- Removed the "ITALIAN MACHINERY. FOUND STORIES." line.
- Kept the "Cars worth finding" heading and introductory sentence.
- Removed the collection filters.
- Each car title is a single line: year + name.
- Clicking a car opens a gallery layout with 12 detail-photo slots (exterior, interior, wheels, upholstery, engine bay, boot, etc.).

## Important image note
The original package contains 12 small mockup/crop images, one for each cover card. It does not contain 12 distinct detail photographs for each car. The gallery therefore includes clearly labelled placeholders for the 12 detail views, rather than pretending that duplicate images are real detail photos.

## Publish to GitHub Pages
Upload/replace `index.html`, `styles.css`, and `script.js` in the root of your `italianfinds` repository, and upload the included `assets` folder at the repository root. Commit the changes to the `main` branch.
